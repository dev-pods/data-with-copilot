# Data + GitHub Copilot para soluções de dados

_Use o GitHub Copilot para gerar queries SQL, manipular DataFrames, fazer análise exploratória e criar visualizações — aplicando boas práticas de ponta a ponta._

## Boas-vindas

- **Para quem é**: engenheiros de software, engenheiros de dados, cientistas de dados e qualquer pessoa que trabalhe com Python e análise de dados.
- **O que você vai aprender**: usar recursos avançados do GitHub Copilot (autocompletar, chat inline, `/explain`, `/fix`, `/doc`, `@workspace`) aplicados a SQL, pandas, EDA e visualização.
- **O que você vai construir**: um fluxo completo de análise sobre uma base de ~32 mil vinhos — de queries SQL a gráficos profissionais.
- **Pré-requisitos**:
  - Conta GitHub com **GitHub Copilot** ativo
  - Noções de Python e análise de dados

Neste exercício, você vai:

1. Gerar queries **SQL** (agregações, `HAVING` com subquery e `JOIN`) a partir de linguagem natural.
2. Manipular **DataFrames** com pandas (limpeza, `groupby`, feature engineering).
3. Realizar **EDA** (estatísticas, outliers por IQR, valores ausentes).
4. Criar **visualizações** com matplotlib e seaborn.
