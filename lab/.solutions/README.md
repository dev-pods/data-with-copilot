# Gabarito (referência do instrutor)

Esta pasta contém as **soluções de referência** de cada módulo do workshop.

- `sql_queries.py` → `sql_module/queries.py`
- `pandas_transformations.py` → `pandas_module/transformations.py`
- `eda_analysis.py` → `eda_module/analysis.py`
- `viz_plots.py` → `viz_module/plots.py`

Use apenas para conferência e apoio. Durante o workshop, o objetivo é que os
participantes construam as soluções com o apoio do GitHub Copilot. Existe mais de
uma resposta correta — o validador (`lab/check.py`) aceita qualquer
implementação que produza o resultado esperado.
